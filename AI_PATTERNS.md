# AI Implementation Patterns

The generated projects use twelve practical patterns: RAG, document intelligence, forecasting, anomaly detection, risk scoring, recommendation, optimization, classification/triage, support copilot, agentic workflow automation, KPI/root-cause analytics, and compliance/policy monitoring.

Each project is runnable as-is and is intentionally designed as a baseline. Domain-specific production systems should replace demo data, model logic, controls, and integrations with validated components.
